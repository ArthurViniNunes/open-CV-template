An open-source **Curriculum Vitae (CV) template** built with **HTML, CSS, and Vanilla JavaScript**, designed to help developers, students, and professionals create clean, modern, and printable online resumes.

This project is intended to be **forked, customized, and reused** by anyone who wants to build their own professional CV.

---

## 📌 About the Project

This repository provides a **single-page interactive resume template** that includes:

- 🖨️ Print-ready layout
- ✍️ Professional typography
- 📱 Responsive design
- ⚡ No external dependencies

Everything is implemented in a single `index.html` file, making it easy to edit, maintain, and deploy.

**Main goal:**

> 👉 Help people build and publish their own CVs quickly using a simple open-source template.

---

## 🔁 How to Use This Template

### 1️⃣ Fork the Repository

Click the **Fork** button at the top-right of this repository on GitHub.

This will create your own copy.

---

### 2️⃣ Clone Your Fork

Clone your repository using:

```bash
git clone https://github.com/your-username/your-repository.git
```

---

### 3️⃣ Customize Your Resume

Open `index.html` and edit the content.

You can update:

- Full name  
- Job title  
- Contact information  
- Professional summary  
- Technical skills  
- Work experience  
- Education  
- Languages  
- Portfolio links  

All sections are clearly structured in HTML for easy editing.

---

### 4️⃣ Publish for Free (GitHub Pages)

Host your resume online for free:

1. Go to **Settings → Pages**
2. Select the **main** branch
3. Choose **/root**
4. Click **Save**

Your CV will be available at:

`https://your-username.github.io/your-repository/`
